# Mindcuit

An emotional wellness website made by Alabi Faizat Aderomola.

## Files
- `index.html`, `try.html`, `recommendations.html`, `sounds.html`, `about.html`, `contact.html`, `privacy.html`, `404.html`
- `css/styles.css`, `js/main.js`, `js/sounds.js`, `img/`

## Publish on GitHub Pages
1. Upload all files to a GitHub repository (with `index.html` at the top level).
2. Go to Settings > Pages. Under Build and deployment, choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
3. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
4. In `index.html`, replace `https://YOUR-USERNAME.github.io/mindcuit/` with your real link so the share preview works.

## Contact form (optional)
Out of the box, the form opens the visitor's email app. To send messages straight to your inbox, create a free Formspree form with faizatalabi90@gmail.com, copy its link (like `https://formspree.io/f/abcdwxyz`), and paste it into `FORM_ENDPOINT` at the top of `js/main.js`.
